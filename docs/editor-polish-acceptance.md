## 1. 准备与启动保护

在项目目录运行：

```powershell
npm run dev:ui
```

打开终端给出的地址，确认标注“本地演示”。使用同一浏览器、主机名和端口检查恢复。首次没有有效草稿时直接显示空白材料表单；有旧稿时按下表操作。

| 操作 | 预期结果 |
| --- | --- |
| 打开或刷新已有内容的 App | 显示上次草稿标题和阶段，暂不自动进入编辑器 |
| 在选择页等待，再刷新 | 仍能看到原稿，空白工作区未覆盖它 |
| 点击“新建演示”，然后取消 | 原稿仍保留，可继续打开 |
| 点击“继续上次草稿” | 恢复原阶段、选中页、内容、配图与格式；本次撤销历史重新开始 |
| 继续后先下载成稿备份，再确认新建 | 回到空白输入表单，主题、材料、受众和目的为空；新稿替换单一自动保存稿 |
| 在选择页导入另一份稿件或打开完整示例 | 需确认替换；导入失败时不以半成品覆盖旧稿 |

新稿的默认页数仍为 6。旧版本自动填入的“项目评审同事”和“说明项目成果，争取下一阶段支持”本身不算用户稿件；短材料、非空主题、自定义听众/目标或已生成大纲/文稿均可恢复。

如果读取失败，界面应暂停自动保存并保护已有存储。期间有新的编辑时，“重新读取”需要确认可能替换这些未保存编辑；成稿先下载备份，材料可先复制保留。此异常路径需在可控失败环境单独复验。

## 2. 单页字号

1. 打开完整示例或继续已有成稿，选择一页有标题、核心信息和正文的页面。
2. 在右侧“文字字号 · pt”依次设置 **38、20、24**。确认画布即时变化，其他页保持原设置。
3. 修改一次字号后撤销、重做，确认数值和画布同步。复制该页，再调整副本，原页不应变化。
4. 点击“恢复自动”，确认当前页恢复基于内容的自动字号；再撤销，手动设置应恢复。
5. 等待“已保存到本机”，刷新并点击“继续上次草稿”，检查字号、页码和图片恢复。
6. 下载草稿备份并重新导入，检查字号仍保留；含图文稿使用 `.huiye.zip`。
7. 导出 PPTX，在 PowerPoint/WPS 中分别选中标题、核心信息和正文，核对字号与文字可编辑性。

只修改一个字号时，其他项目仍可保持“自动”。手动字号在切换版式、主题和导出时不应被悄悄缩小；字号过大导致文字放不下时，应提示减小字号、精简文字或拆页，并阻止有明显溢出的导出。字体渲染差异仍需目标软件检查。

## 3. 区分三个示例操作

| 入口 | 作用 | 是否替换整稿 |
| --- | --- | --- |
| 材料页“使用示例材料” | 填入虚构咖啡店材料与设置 | 只修改材料表单；已有大纲会按材料变化处理 |
| 顶部“打开示例” | 打开固定六页成稿并持久化配图 | 是；存在内容时先确认 |
| 编辑器“页面图片 → 示例图片” | 选择咖啡照片或等待时长图，添加到当前页 | 否；当前页正文保留，配图可被替换 |

顶部完整示例和编辑器单页示例图片在本地与 Anna 环境均显示。素材在仓库中提供，使用前仍走图片校验与保存路径；不是网络搜图或 AI 生图。照片仅作场景示意，门店、人物及数字均为虚构。

单页图片复验：打开弹窗后先取消，确认内容不变；再选择一张图，确认只有当前页变化；撤销/重做检查原图恢复。保存期间按钮不能重复提交，失败应保留原图并显示错误。图表默认“完整显示”，以免裁掉坐标或数字。

在 Anna 中，这些手工示例操作为 **0 次模型调用**，但图片会占用文件存储空间。点击“生成大纲”“生成幻灯片”或“AI 改写当前页”则属于真实模型操作；不要为验收示例入口额外生成。

## 4. 缩略图栏与页面空间

- 在桌面高度下查看六页示例，检查缩略图栏比旧版容纳更多内容、间距更紧凑，标题“页面”保持可见。
- 滚动缩略图栏至末页，确认所有页可选中，选中态与画布一致；不要要求不同窗口高度下都显示固定页数。
- 新增/复制页面后检查滚动与最后一页可达性；窄屏仍应采用原有横向页面列表，不强套桌面高度。

这部分改善可用空间，不改变页数、文稿内容或导出尺寸。

## 5. 大纲提示词验证边界

写作规则参考 Presentations 技能中受众、事实、标题及写作质量原则，具体约束、JSON 合同与额度边界见 [大纲提示词与调用合同](outline-prompt.md)。每次生成大纲仍为一次调用、最多 1600 输出 tokens，无新增自动修复或重试；提示文字变化可能增加输入 tokens，不能据此宣称实际 CU 不变。

离线合同测试不能证明模型已正确按受众组织内容或抵抗材料中的指令。后续平台抽样可使用一份复盘材料和一份知识讲解材料，各生成一次大纲，先核对标题、页间重复、数据口径、来源与限制，再决定是否生成全文。此处只记录建议步骤，不宣称已完成真实模型质量验收。
