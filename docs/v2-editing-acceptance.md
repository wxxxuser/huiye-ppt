# 第二版第一批：页面管理与自动保存本地验收

本批次范围：页面新增/复制/删除、通用撤销/重做、材料/大纲/编辑器自动保存。这里使用本地演示，不调用 Anna LLM，也不上传 App。模板导入、多人协作和多文稿列表不在本批次范围内。

本文保留第一批功能的历史验收结果，操作步骤已适配当前启动选择页。最新的启动保护、字号与示例图片检查见 [编辑体验验收](editor-polish-acceptance.md)；文末的 63 项测试记录不代表本轮最终结果。

## 1. 启动与验收准备

在 `huiye-ppt` 项目目录执行：

```powershell
npm run dev:ui
```

打开终端显示的 [本地页面](http://127.0.0.1:5174/)。页面应显示“本地演示”，模型调用次数为 0。端口固定为 `5174`；如果已被占用，先关闭占用该端口的旧开发进程，再启动，不要改用另一个端口后误以为原草稿丢失。

本地草稿由浏览器按网站来源保存，请始终使用同一浏览器和 `http://127.0.0.1:5174/`。无痕窗口、其他浏览器、`localhost` 或其他端口拥有不同存储。已有成稿需要保留时，先点击“草稿备份”；本 App 只自动保存一份当前工作稿，新建或导入会替换它。

每次刷新前，**等待页面显示“已保存到本机”**。自动保存使用约 650 ms 的防抖，实际完成时间还取决于存储操作；不要仅凭等了 650 ms 判断保存成功。

刷新后，有有效旧稿时会先显示“继续上次草稿”，点击后才恢复原阶段；等待选择时不应覆盖旧稿。空白新稿的主题、材料、听众和目标均为空，占位提示不是实际内容。

## 2. 材料阶段：未完成输入也能恢复

1. 点击右上角“新建”，确认“开始新稿”。
2. 将标题留空，材料填写 `这是尚未写完的项目材料，先检查保存。`，保持不足 80 字。也可暂时清空听众或目标。
3. 等待“已保存到本机”，刷新页面。
4. 点击“继续上次草稿”，检查回到“输入材料”，未完成内容、换行和空字段均保留。
5. 点击“生成演示大纲”：应提示补齐必填项或材料长度；自动保存允许未完成输入，不等于生成校验被取消。
6. 补写标题，点击“撤销”再“重做”，检查材料阶段同样支持历史操作。

## 3. 大纲阶段：修改和空白内容恢复

1. 点击“使用示例材料”，再点“生成演示大纲”。这是本地固定规则演示，不调用模型。
2. 修改文稿标题、某页标题和核心信息；用上/下按钮调整一页的顺序。
3. 暂时清空其中一页的标题或核心信息，等待“已保存到本机”，刷新。
4. 点击“继续上次草稿”，应回到“确认大纲”，顺序、修改内容及空白输入均保留。刷新前的撤销历史不恢复。
5. 补齐该页标题和核心信息，再生成演示幻灯片。

另外检查材料过期保护：返回“输入材料”修改材料，再回“确认大纲”。旧大纲应保留供查看，并提示材料已修改、需要重新生成大纲；不能把旧引用当作新材料的结果直接生成整稿。完成后重新生成大纲再继续。

## 4. 页面新增、复制、删除与选中页

可点击“打开示例”获得完整成稿后操作。下面每一步都可用顶部“撤销”“重做”检查。

| 操作 | 预期结果 |
|---|---|
| 选择中间页，点击“新增页” | 当前页之后新增空白页并选中它；总页数增加 1；空白页没有虚构的材料引用 |
| 空白页不填写，等待保存后刷新并点击继续 | 空白页、页数和选中位置恢复；内容不足以导出时应有提示，不能因此丢失草稿 |
| 为新增页填写标题、正文要点、核心信息和备注 | 预览更新；需要引用时在“材料出处”勾选对应原文 |
| 点击“复制页” | 在当前页后出现独立副本；标题、正文、备注和来源关联复制完整 |
| 只修改副本的标题、正文或来源 | 原页面保持原内容，两个页面不共享可变内容 |
| 删除首、中、尾位置的页面 | 页数减少，选中页落在有效位置；画布、缩略图和页码一致 |
| 删除后撤销，再重做 | 被删页连同内容恢复，重做后再次删除 |
| 上移或下移当前页，再撤销 | 顺序恢复，选中页与画布对应正确 |
| 选中非第一页，等待保存后刷新并点击继续 | 恢复同一选中位置与内容 |

边界检查：手工文稿为 **1–30 页**。删除至 1 页时“删除页”禁用；新增或复制至 30 页时对应按钮禁用。初次 AI 生成契约仍为 4–10 页；当前界面页数快捷选项为 6/8/10。手工增删后的大纲再次生成整稿时可能要求返回材料重新生成大纲，这是为了保留生成契约和预算限制。

## 5. 撤销/重做与文本分组

| 场景 | 操作与预期 |
|---|---|
| 连续输入 | 在同一输入框连续快速输入一段文字，输入间隔小于 800 ms；一次撤销应回到这组输入开始之前，而非逐字符撤销 |
| 停顿分组 | 输入一段，停顿超过 800 ms，再输入另一段；撤销应先移除后一段 |
| 失焦分组 | 输入后点击另一个字段，再回原字段输入；两次编辑应分开撤销 |
| 结构和样式 | 改版式、换配色、排序、增删复制后撤销/重做，内容及预览应同步 |
| 重做分支 | 撤销一次后输入新内容；原来的“重做”应不可用 |
| 快捷键 | Windows 用 `Ctrl + Z` 撤销、`Ctrl + Y` 重做；macOS 用 `Cmd + Z` 撤销、`Cmd + Shift + Z` 重做。焦点在编辑输入框时也应作用于 App 历史 |

历史最多保留最近 **50 步**。它只存在于当前打开的页面中；刷新、导入其他稿、打开示例或新建会清空历史，但已完成自动保存的当前内容仍可恢复。切换制作阶段和选中页面用于导航，不单独增加撤销步骤。

AI 用量是本工作稿的调用记录，**不会随撤销减少**。本地可以通过“用量”查看规则演示记录，确认撤销生成内容后记录仍保留；这些记录标记为本地模拟、不消耗额度。本地验收不需要为验证账本而发起真实 AI 请求。

## 6. 旧草稿、导入和单稿存储

1. 点击“导入汇页草稿”，选择仓库内 `examples/huiye-demo.huiye.json`，确认导入。
2. 应进入编辑器并显示原有内容。等待保存后刷新，点击“继续上次草稿”后应能恢复；旧 Deck 自动包装为新的工作区保存格式。
3. 编辑一页，再导入其他草稿。确认导入后，撤销不能回到导入前的工作稿；当前工作稿与用量记录采用导入稿内容。
4. 下载“草稿备份”后再新建。确认新建后材料阶段出现，主题、材料、听众、目标、撤销记录和新工作稿用量均为空；刷新不能找回被替换的旧稿，应从备份导入。

目前没有“我的文稿”列表。材料和大纲阶段依赖自动保存；编辑器的“草稿备份”导出可恢复的成稿，纯文字为 `.huiye.json`，含图片为 `.huiye.zip`，均不导出整个撤销历史。

## 7. 导出与窄屏回归检查

以下步骤用于复验；本轮已完成浏览器下载及桌面/窄屏检查，PowerPoint / WPS 视觉验收仍需在目标软件中进行。

- 整理一份包含新增、复制和删除操作的文稿，为所有保留页补齐标题和正文；导出 PPTX，检查页数、顺序、标题、中文和演讲备注是否与当前编辑器一致。
- 保留空白新增页时点击导出，应明确要求补全必要内容；草稿仍应正常保存。
- 在 PowerPoint 或 WPS 中打开导出文件，检查文字/形状可编辑、没有明显文字溢出或遗漏。这一步需要目标软件，不能只用浏览器预览替代。
- 将浏览器视口缩至约 390×844，检查新增/复制/删除、撤销/重做和保存状态可见或可通过正常滚动到达，输入及页面切换可用。
- 用 `npm run build`、`npm test`、`npm run validate` 做本地回归。这些命令不会调用真实模型；Anna 容器或 staging 的真实联调是后续单独步骤。

## 第一批历史观察结果与剩余边界

本批次 `npm test` 的 63 项测试、`npm run build`、`npm run validate` 和 `npm run test:host` 全部通过。回归测试和最终浏览器复验均确认：编辑旧成稿不会覆盖独立修改的新大纲，刷新后该大纲仍保留；最终页面无浏览器警告或错误。

浏览器已观察到：材料和大纲的未完成输入刷新恢复、空白页保存恢复、复制后独立编辑、删除的撤销/重做、排序撤销，以及选中页恢复。

本轮还完成了 1180×780 桌面和 390×844 窄屏检查，窄屏无页面横向溢出；删除至 1 页按钮禁用，连续撤销恢复全部 8 页。实际下载 PPTX 含 8 页，程序检查确认新增页、副本的独立标题、正文和 S2 引用；浏览器未报告警告或错误。官方本地宿主的 hello、storage 和窗口标题检查通过，模型关闭。

验收使用独立的 5176 端口，未覆盖日常 5174 的浏览器草稿。当前改动未上传，验收未调用真实模型；尚未验证 PowerPoint / WPS 中的逐页视觉效果、staging 上的新工作区格式、跨设备恢复和真实 AI 质量。
