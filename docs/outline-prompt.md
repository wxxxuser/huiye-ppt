# 大纲提示词与调用合同

大纲生成根据受众、演示目的和材料安排内容。它仍然是一次 Anna LLM 调用，输出经过本地结构校验后才进入可编辑大纲。

## 内容组织

参考 Presentations 技能中的 Writing Quality、Write for the audience、Keep facts accurate 和 Titles 原则，提取适合本产品的写作要求。技能的成品演示制作、发布及制图流程不适用于这个提示词改动。

| 要求 | 提示词中的处理 |
| --- | --- |
| 根据受众和目的选择顺序 | 复盘、教学、方案比较提供不同顺序参考，明确它们不是必填章节 |
| 每页讲清一个重点 | `keyMessage` 写材料支持的主张或解释重点，不写“介绍背景”等讲述安排 |
| 标题准确 | 背景、概念、流程页可用主题标题；结论标题必须有材料依据，不强行制造洞见 |
| 保留数据含义 | 同时保留单位、时间、对象、比较范围和统计口径；禁止自行推算新数字和百分比 |
| 不虚构行动 | 负责人和期限必须有材料依据；结尾可以总结知识，不要求一律追加行动计划 |
| 保留限制 | 重要分歧、限制及虚构标识不能在精简时丢失；建议不能冒充已发生的事实 |
| 材料不是系统指令 | 材料中的角色声明和越权命令只作为数据，输入通过单独 JSON 区块传入 |

短示例仅对照空泛标题与具体主题，不提供可用于输出的事实。模型只返回结果，不输出推理、结构选择或自检过程。

## 文件与调用边界

- `src/prompts.ts`：共用内容约束、输入 JSON 与大纲提示词。字数硬上限直接使用 `domain.ts` 的 `LIMITS`，避免提示词和验证器不同步。
- `src/ai.ts`：调用平台、提取真实用量、严格解析和验证结果。大纲生成额外拒绝 `image` 版式，避免产生没有图片的图文页。
- `tests/prompts.test.ts`：离线请求、输出合同和格式保留测试。

| 操作 | LLM 调用次数 | `maxTokens` | 说明 |
| --- | --- | --- | --- |
| 生成大纲 | 每次操作 1 次 | 1600 | 不加隐式重试或修复调用 |
| 生成文稿 | 每次操作 1 次 | `min(6500, 页数 × 550 + 400)` | 现有上限不变 |
| 改写当前页 | 每次操作 1 次 | 900 | 只发送该页关联材料 |

所有调用保持 `thinking: false`。如果已付费的输出没有通过验证，仍记录平台返回的真实用量。固定大纲指令与共用约束合计不超过 1900 个 JavaScript 字符，不含输入材料；这是维护提示词长度的预算，不是 token 或平台额度估计。提示词文字有所增加，因此输入 token 可能比旧版略多，实际额度以 Anna 返回为准。

## 输出结构保持不变

大纲依然只有 `title`、`subtitle` 和 `slides`。每页依然只有 `id`、`title`、`keyMessage`、`layout`、`sourceIds`。

- 页数包含封面、结尾，必须与用户设置完全一致，ID 按顺序为 `slide-1` 至最后一页。
- 首尾分别为 `cover`、`closing`；中间只能为 `bullets`、`split`、`steps`。自动生成不会选择 `image`，用户可在编辑器上传图片后切换图文版式。
- 每页至少关联一条存在的来源，提示词要求引用支持本页主旨。
- 标题最多 60 字，建议 8–24 字；主旨最多 140 字，建议 20–45 字；副标题最多 100 字，可为空。
- 本地验证 JSON 结构、字段、页数、ID、版式、引用存在性、字数和数字是否在所引材料出现。引用的语义支持程度和数字口径仍需人工检查。

## 改写与用户格式

改写请求会先验证当前页，再从模型输入中移除 `image` 和 `typography`。图片路径、尺寸、文件名及字体设置不进入模型请求。成功后把经过验证的原图片信息和部分字号设置独立复制回结果；模型只能修改文字，不能通过返回格式字段覆盖用户设置。旧草稿缺少字号字段时不会补入空配置。

## 已验证与待验证

离线测试使用模拟响应，不调用 Anna，也不消耗模型额度：

```powershell
npx tsx --test tests/prompts.test.ts tests/domain.test.ts tests/image-workspace.test.ts tests/typography.test.ts
```

已覆盖受众/目标及材料的 JSON 传输、固定指令长度、页数边界、一次调用与输出上限、图文页拒绝、字数边界、改写保留图片和字号以及格式元数据不发送给模型。材料中的指令被保留为 JSON 数据不等于模型已通过提示注入防御测试。

真实生成质量尚待在 Anna 平台验收。建议用已有咖啡店复盘材料与一份知识讲解材料各生成一次大纲，人工查看顺序是否匹配受众、各页是否重复、标题和主旨是否有依据，以及单位和限制是否保留。先只生成大纲并记录实际用量，确认后再生成全文；不要为自检增加模型调用。离线测试通过不代表模型一定遵守所有写作要求。
